# ⛺ Outdoor Equipment Rental System (Dart OOP Challenge)

Aplikasi konsol berbasis **Dart murni** yang dirancang untuk mengimplementasikan prinsip-prinsip *Object-Oriented Programming* (OOP) secara ketat pada domain sistem manajemen inventaris dan transaksi penyewaan perlengkapan *outdoor*. 

Proyek ini berfokus pada pemodelan domain yang aman (*domain modeling*), di mana tipe data dan struktur kelas dikonstruksi secara defensif untuk menolak kondisi yang tidak valid atau mustahil dalam aturan bisnis nyata.
